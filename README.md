# FitTracker

Die App „FitTracker“ dient als digitales Ernährungstagebuch, in dem Nutzer ihre täglichen Mahlzeiten und deren Nährwerte erfassen können. Sie ermöglicht einen übersichtlichen Einblick in die persönliche Nährstoffzufuhr und die eigenen Ernährungsgewohnheiten. Ziel der Anwendung ist es, Nutzern dabei zu helfen, ihre Ernährung besser nachzuvollziehen und bewusster zu gestalten.
